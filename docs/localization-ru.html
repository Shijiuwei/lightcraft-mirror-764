LightCraft на русском

Выберите Правка → Язык → Русский или Настройки → Общие → Язык. Выбор применяется сразу и сохраняется для следующего запуска (language: "ru" в ui.json).

Русский каталог охватывает меню, сочетания клавиш, библиотеку, обработку, кадрирование, маски, импорт и экспорт, настройки, встроенные стили и профили, историю, даты и сообщения о ходе работы. Технические ошибки из нижних уровней, как и в других языках, остаются на английском; строки, которых ещё нет в каталоге, показываются по-английски.

Имена файлов, идентификаторы команд, шаблоны и названные вами альбомы, стили и метаданные не переводятся. Шрифт интерфейса Inter содержит кириллицу, дополнительные шрифты не нужны.

Сопровождение и проверка

Постоянные тексты: crates/ui-egui/locales/ru.json. Сообщения со значениями: crates/ui-egui/locales/ru-formats.json. Английские ключи не меняются; заполнители проверяются компилятором Rust при сборке. Английские окончания множественного числа скрываются через {:.0}.

cargo test -p lightcraft-ui-egui i18n::tests -- --nocapture
LIGHTCRAFT_LANGUAGE=ru lightcraft-cli snapshot --demo -o russian.png --size 1600x1000
